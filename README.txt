Split Lah! · PWA v1.5.3

核心功能：
- 建立分帳時直接加入參與者
- 新增 / 編輯 / 刪除消費
- 選擇付款人與參與者
- 自動平均分帳，並合併同一對人之間的雙向欠款
- 每筆結算轉帳可標記已付 / 撤銷
- 顯示結算進度
- 一鍵全部結清
- 全部完成後自動標記已結清
- 可重新打開已結清帳單
- 修改或刪除消費後清除舊結清狀態並重新計算
- 首頁進行中帳單優先，已結清帳單排後
- localStorage 本機保存
- PWA manifest、App icon、Service Worker 離線快取

手機安裝：
PWA 完整功能需要部署在 HTTPS 網址。
iPhone：Safari → 分享 → 加入主畫面。
Android Chrome：使用「安裝應用程式 / 加到主畫面」。

目前資料仍只存在單一裝置的瀏覽器 localStorage，尚未加入雲端同步。


v1.3 品牌更新
- App 正式命名為 Split Lah!
- Tagline：你記帳，我算數。
- 網頁標題、PWA 安裝名稱、主畫面名稱、README 全部統一
- 保留原本暖米白 + 深綠色視覺


v1.4 新增：刪除整張帳單
- 帳單頁右上角新增「•••」設定入口
- 刪除入口收在第二層，避免誤觸
- 刪除前會再次確認
- 刪除整張帳單時，參與者 / 消費 / 結算記錄會一起移除
- 刪除後自動回到帳單列表
- Service Worker cache 已更新，方便已安裝的 PWA 取得新版


v1.5 新增：各自金額分攤
- 新增「平均分 / 各自金額」兩種分攤方式
- 各自金額模式可為每位參與者輸入不同金額
- 保存前會檢查各自金額合計是否等於消費總額
- 結算會按每個人的實際負擔計算，不再強制平均
- 舊有消費沒有 splitMode 時仍自動按「平均分」處理，保留向後相容
- 編輯既有「各自金額」消費時會載回每人的金額


v1.5.1 修复：示范帐单删除后复活
- 原因：旧版只要检测到 bills 为空，就会重新建立「示范 · 晚餐」
- 修正：示范资料只会在这台设备真正第一次启动、完全没有任何已保存状态时建立一次
- 用户主动删除全部帐单后，空白状态会被尊重；重新开启 App 不会再自动生成示范帐单
- 沿用原本 localStorage key（splitBillMvpV1），现有真实帐单不会被清除

v1.5.2 修复：结算金额分厘误差
- 平均分与结算计算改为以整数分处理，确保每笔转账与每个人的应付 / 应收金额对得上
- 平均分无法整除时，余数会在参与者之间轮流分配
- 各自金额会按分舍入并补齐尾差，使结算总额保持平衡
- 更新 Service Worker cache，让已安装的 PWA 可取得新版

v1.5.3 修复：保留不同收款对象的转账路线
- 按每笔消费记录实际欠款，再只抵销同一对参与者之间的反向欠款
- 欠款人欠不同对象的金额会分别列出，不再把多位收款人合并成同一收款人
- 所有金额使用整数分计算，结算转账与每个人的应付 / 应收保持一致
